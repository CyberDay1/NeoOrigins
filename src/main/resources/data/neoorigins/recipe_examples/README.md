# Origin-Gated Recipe Examples

These JSON files demonstrate the three origin-gate condition shapes accepted
by `neoorigins:origin_gated_crafting`. They live in `recipe_examples/`
(NOT `recipe/`) so vanilla's recipe loader never scans them; they're
documentation only.

To use one of these recipes in your own datapack, copy it into
`data/<your_namespace>/recipe/<some_name>.json` and adjust the gates +
inner recipe to suit.

See `docs/RECIPE_CONDITIONS.md` for the full reference.
