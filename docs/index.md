# NeoOrigins
{: .fs-9 }

NeoForge port of Origins with a JSON-first power framework, an event dispatcher, projectile + VFX pipeline, and an extensive pack-author and Java API surface.

## Start here

- **New to pack making**: [Getting started](guides/getting-started) builds a first origin, then the [Cookbook](COOKBOOK) has patterns to copy.
- **Looking for a task** ("give an ability a mana cost", "make a toggle"): the [Start here](START_HERE) page has an "I want to..." table.
- **Server admins**: [Content Config](CONTENT_CONFIG), [Gameplay Config](GAMEPLAY_CONFIG), [Admin Config](ADMIN_CONFIG) and [Power Overrides Config](POWER_OVERRIDES_CONFIG).
- **Players**: the [Origin Catalog](ORIGINS) and the [Class Catalog](CLASS_CATALOG).
- **Java extenders**: the [Java API](JAVA_API) reference and the [Custom Projectiles & VFX](CUSTOM_PROJECTILES) guide.
- **Upgrading from 1.x**: the [Migration Guide](MIGRATION).
- **Prefer a visual tool?** The [Web Editor](https://cyberday1.github.io/NeoOrigins/editor/) builds origin and mob-origin JSON in the browser.

This site documents the Minecraft 26.x builds. Where the 1.21.1 build behaves differently, the page says so in a note that starts **1.21.1 vs 26.x**.
