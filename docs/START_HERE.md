# Start here

NeoOrigins content is plain JSON in a datapack. This page sends you to the right place for the job at hand.

## I want to...

| Task | Read |
|---|---|
| Make my first origin and power | [Getting started](guides/getting-started.md) |
| Copy a working pattern (diet, dash, aura, projectile...) | [Cookbook](COOKBOOK.md) |
| Find the power type for an effect | [Power Types](POWER_TYPES.md): one table per category |
| Learn the fields every power accepts | [Power basics](concepts/power-basics.md) |
| Give an ability a mana, stamina or hunger cost | [Give an ability a cost](guides/costs.md) |
| Make a power drain a bar while it is switched on | [Costs & upkeep](concepts/costs-and-upkeep.md) |
| Make something the player can switch on and off | [Make a toggle](guides/toggles.md), then [Toggles](concepts/toggles.md) |
| Put an ability on its own key | [Keybinds](concepts/keybinds.md) |
| Show a cooldown icon on the HUD | [Cooldowns & HUD](concepts/cooldowns-and-hud.md) |
| Run an effect when something happens (kill, hit, eat, jump...) | [`action_on_event`](powers/core.md#neooriginsaction_on_event) and [Events](EVENTS.md) |
| Look up an action or a condition | [Entity Actions](ACTIONS.md), [Conditions](CONDITIONS.md) |
| Add a class, or see what the built-in classes do | [Custom Classes](CLASSES.md), [Class Catalog](CLASS_CATALOG.md) |
| Port an Origins (Fabric) pack | [Mod Compatibility](COMPATIBILITY.md), [Migration Guide](MIGRATION.md) |
| Debug a pack that loads wrong | [Test and debug a pack](guides/testing.md) |
| Tune a built-in power on my server without a datapack | [Power Overrides Config](POWER_OVERRIDES_CONFIG.md) |
| Turn origins, classes or classic mode on and off | [Content Config](CONTENT_CONFIG.md) |

## By role

- **Pack authors:** [Getting started](guides/getting-started.md), then the [Cookbook](COOKBOOK.md), with [Power Types](POWER_TYPES.md), [Actions](ACTIONS.md) and [Conditions](CONDITIONS.md) open beside it.
- **Server admins:** [Content Config](CONTENT_CONFIG.md), [Gameplay Config](GAMEPLAY_CONFIG.md), [Admin Config](ADMIN_CONFIG.md) and [Power Overrides Config](POWER_OVERRIDES_CONFIG.md).
- **Players:** the [Origin Catalog](ORIGINS.md), the [Class Catalog](CLASS_CATALOG.md) and [Client Config](CLIENT_CONFIG.md) for keys and HUD options.
- **Java and KubeJS developers:** [Java API](JAVA_API.md) and [KubeJS Integration](KUBEJS.md).
