# Power-type ids that are authorable (listed in the power.schema.json `type`
# enum) but have NO structured `oneOf` branch, so an author writing one gets the
# permissive `type.not.enum` fallback: no field validation, no form, a raw-JSON
# box in all three editors.
#
# THE TARGET IS ZERO. This file exists only to hold the line while the gap is
# closed one power at a time; it is checked by `./gradlew powerEnumCheck`, which
# fails if an id is ADDED here and equally if a line goes stale (the id gained a
# branch, or left the enum). Shrinking it is the work; growing it is a
# regression.
#
# To remove a line: give the power a FieldSpec list in BuiltinPowers, run
# `./gradlew generatePowerSchema`, then delete the line. That works for a REAL
# power type -- one with a PowerType class, a Config record and a PowerTypes
# registration. It does NOT work for the 2.0-era alias ids below (see the next
# paragraph but one): they have none of those things, so BuiltinPowers' own two
# gates (PowerEnumCheck "descriptor with no registration" and
# SchemaFormCheck.auditPowerFieldSpecs "no Config record resolved") reject them,
# and both are right to. Those need a descriptor table of their own.
#
# NOT listed here, for two reasons that are not "gap":
#
#   * the container types (the ids OriginsMultipleExpander.isMultipleType
#     accepts), whose properties are arbitrary author-chosen sub-power keys, so
#     there is no branch to write. PowerEnumCheck exempts those directly,
#     permanently.
#
#   * the FOREIGN legacy import surface -- the origins:/apace:/apoli:/apugli:
#     spellings the alias table and the compat import translation accept. Those
#     ARE a gap, but a different one: branches are generated from FieldSpec
#     lists and an imported spelling has no descriptor of its own, so closing it
#     means folding the id into its translation target's branch. PowerEnumCheck
#     counts them under the MAX_UNBRANCHED_LEGACY ratchet instead.
#
# The 29 `neoorigins:` entries below are NOT that. They are native, first-party,
# authorable 2.0 power-type ids that LegacyPowerTypeAliases remaps to a modern
# type at load. They were being counted under MAX_UNBRANCHED_LEGACY, because
# PowerEnumCheck.legacyImportSurface() read the alias table's SOURCE ids without
# filtering the mod's own namespace back out. That made the ceiling read 32 and
# this file read 1, i.e. "one native id left, target is zero", while thirty
# native types actually had no branch. They are itemized here now. Their arrival
# is a RECLASSIFICATION of an existing gap, not a new one -- no id lost a branch.
#
# This list is measured per branch. Do not copy it between 1.21.1 and 26.x --
# the registries differ, so the real gap differs.
